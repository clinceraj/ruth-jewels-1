# Ruth Jewels - Handpicked Indian Classical Jewelries

A beautifully crafted website showcasing handcrafted South Indian jewellery featuring traditional designs with modern elegance.

## About Ruth Jewels

Ruth Jewels specializes in handpicked Indian classical jewelries inspired by heritage and tradition. Each piece is meticulously designed to feel timeless, personal, and radiant. We celebrate the art of jewellery-making with a modern, elegant finish while honoring centuries of tradition.

## Features

✨ **Featured Collections Gallery** - Browse our stunning jewelry collections

## Setup Instructions

To run locally:

```bash
git clone https://github.com/clinceraj/ruth-jewels-1.git
cd ruth-jewels-1
```

### Local Development

**Option 1 - Direct File:**
Simply open `index.html` in your web browser

**Option 2 - Local Server:**
```bash
python -m http.server 8000
# Then visit http://localhost:8000 in your browser
```

For Python 2:
```bash
python -m SimpleHTTPServer 8000
```
